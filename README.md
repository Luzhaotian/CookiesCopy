# Cookies Copy

一款 Chrome 浏览器扩展，用于查看、搜索和复制当前页面的 Cookie 信息。

## 功能

- **Cookie 详情展开** — 点击任意 Cookie 行展开完整属性（值、域名、路径、过期时间、安全、HttpOnly、SameSite）
- **独立复制按钮** — 每行右侧独立的复制按钮，一键复制 Cookie 值
- **搜索过滤** — 按名称或值实时搜索，支持搜索高亮
- **批量操作** — 全部复制、仅复制键名、仅复制值
- **过滤感知** — 搜索后批量操作仅针对筛选结果
- **导出 JSON** — 将 Cookie 列表导出为 JSON 文件
- **Toast 通知** — 复制、导出等操作即时反馈
- **暗色模式** — 自动 / 浅色 / 深色三档切换

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 将项目文件夹直接拖入扩展页面即可


## 使用

安装后点击浏览器工具栏中的扩展图标，即可查看当前页面的所有 Cookie。
